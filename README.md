# You're the Hero, Copilot's the Cape

## Turning Domain Expertise into AI Superpowers

AI does not replace the expert. It amplifies the expert.

This repository contains the resources, guides, prompts, and demonstration assets developed for the session:

> **You're the Hero, Copilot's the Cape: Turning Domain Expertise into AI Superpowers**

The central idea is simple:

> The people getting the most value from Copilot are not necessarily the people with the cleverest prompts. They are the people who know their craft well enough to teach Copilot how they think.

This project demonstrates how Microsoft 365 Copilot, GitHub Copilot, Copilot Studio, Copilot Cowork, and MCP servers can help turn experience into reusable capabilities.

---

## Featured Project: The Ultimate Entra Advisor

The **Ultimate Entra Advisor** demonstrates how years of Active Directory and Microsoft Entra ID experience can be operationalized through a GitHub Copilot Skill.

The solution combines:

- **GitHub Copilot** as the AI-powered working environment
- **A Copilot Skill** that captures assessment criteria in natural language
- **Microsoft MCP Server for Enterprise** to provide access to live Microsoft Entra tenant data
- **Expert judgment** to interpret results, identify risks, and recommend action

The goal is not simply to teach Copilot how to query Microsoft Entra ID.

The goal is to teach Copilot **how an experienced IT professional assesses a Microsoft Entra ID tenant**.
